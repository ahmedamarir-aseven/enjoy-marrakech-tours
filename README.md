# Enjoy Marrakech Tours

A modern, responsive travel and excursion booking web application for Enjoy Marrakech Tours — offering guided day trips, desert safaris, mountain expeditions, and private transfers across Morocco.

## Overview

Enjoy Marrakech Tours allows travelers to explore hand-crafted tour itineraries from Marrakech, including Atlas Mountains treks, Agafay & Merzouga desert excursions, coastal escapes to Essaouira, and luxury villa pool day passes. The platform provides detailed itinerary overviews, pricing, multi-language support, and direct booking inquiries.

## Key Features

- **Excursion Catalog & Categories**: Browse tours by categories (Day Trips, Desert Safaris, Cultural City Tours, Adventure & Wellness).
- **Tour Details & Pricing**: Full itinerary breakdown, included amenities, departure details, and price transparency.
- **Multilingual Support**: Internationalization (i18n) for travelers worldwide.
- **Interactive Search & Filter**: Quick search to discover experiences by duration, activity type, and destination.
- **Direct Reservation Inquiries**: WhatsApp and direct web booking integration for instant confirmations.
- **Responsive Modern UI**: Built with React 19, Tailwind CSS, and Radix UI primitives for an optimal mobile experience.

## Technologies Used

- **React 19**
- **TypeScript**
- **Vite 7**
- **Tailwind CSS**
- **React Router 7**
- **Radix UI** (Accessible headless primitives)
- **Lucide React** (Icons)
- **Sonner** (Toast notifications)

## Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (version 18 or higher recommended)
- [npm](https://www.npmjs.com/)

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/ahmedamarir-aseven/enjoy-marrakech-tours.git
   cd enjoy-marrakech-tours
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Set up environment variables:
   ```bash
   cp .env.example .env
   ```
   Edit `.env` to configure your optional Google Analytics ID:
   ```env
   VITE_GA_MEASUREMENT_ID=your_ga_measurement_id_here
   ```

4. Start the development server:
   ```bash
   npm run dev
   ```

5. Build for production:
   ```bash
   npm run build
   ```
